# 予页 pagetoyou

本地体验版 v0.1.0。首页沿用暖纸与书信的视觉，点击“开始试用”进入礼物工坊。

## 运行

安装 Node.js 后，在此目录运行 `npm start`，浏览器打开 http://127.0.0.1:4175 。无需安装依赖。使用固定地址可恢复此前保存的浏览器草稿；换端口、浏览器或设备不会共享本地数据。

## 当前能力

- 3D 文字空间：编辑祝福，每行一句；文字球体自动旋转、拖动转向、缩放、暂停。
- 3D 照片树：最多三张照片，可旋转和点击放大。
- 电子相册：按钮翻页、左右滑动及键盘方向键切换。
- 照片长廊：横向滑动、点击放大。
- 标题、署名、文字和空间配色编辑，真实本地照片上传与压缩。
- IndexedDB 保存和恢复一份当前草稿，包含照片；仅保存在此浏览器。
- 原信封贺卡交互原型可从“信封贺卡”进入，尚未与新工坊草稿存储统一。

3D 采用浏览器 CSS 透视与空间变换，不依赖外部图形库。示例照片为程序绘制的风景占位图，可移除后上传自己的图片。为沿用已确认的内容约束，每份礼物最多三张照片。动画尊重减少动态效果偏好。

## 尚未实现

正式账号、云端存储、在线发布与真实礼物分享链接。不要将本地预览地址当作他人可访问的礼物链接。本地草稿在浏览器清理后可能丢失，不承诺永久保存。

## 版本与部署

源文件由本地 Git 管理。原规划及首页原型已单独保存基线提交，本轮功能保存为新的提交和本地版本标签。未配置用户 Git 作者信息时使用仅本次提交有效的 `Pagetoyou Local <pagetoyou@localhost>`，不修改全局 Git 设置。

计划首个可用版本检查后同步 GitHub。当前尚未配置远程仓库。网站使用相对资源路径，可静态托管在 GitHub Pages；本地 `server.cjs` 仅用于预览，无需部署到 Pages。

研究参考：https://a12240.w.wan55.cn/s/9922GW 。浏览器只观察到黑色画面和“光棍节”入口，未获得完整动画，当前文字空间根据用户描述独立实现，未复制其代码或素材。
